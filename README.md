### My Kitty config.

#### Matugen

The colorscheme is generated by [Matugen](https://github.com/InioX/matugen).

If you want generate colors, you can use my [Matugen config](https://github.com/Tschonitsch/matugen).

#### Features

- Cursor trail
- Custom keybindings

#### Keybindings

| Action       | Binding             |
| ------------ | ------------------- |
| Copy         | `C-S-c`             |
| Paste        | `C-S-v`             |
| Increase font | `C-S-=`            |
| Decrease font | `C-S--`            |
| Reset font   | `C-S-Backspace`     |
